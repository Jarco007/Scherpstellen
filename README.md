# Scherpstellen

**ROT Trainingsvoorbereidingstool** — ontwikkeld door [Scherp in Veiligheid](https://scherpinveiligheid.nl)

Scherpstellen helpt trainers om ROT (Regionaal Operationeel Team) trainingssessies beter voor te bereiden door vooraf inzicht te krijgen in de ervaringen en leerdoelen van deelnemers.

## Functionaliteit

- **Startpagina** met uitleg en disclaimer voor deelnemers
- **Vragenlijst** over rol, ervaring, praktijkervaring, leerdoelen en leerstijl
- **Resultaatscherm** met ervaringsniveau (Weinig / Gemiddeld / Gevorderd), trainerinzichten en top 3 aanbevolen oefenscenario's
- **Export naar Google Doc** — profiel kopiëren naar klembord en plakken in nieuw Google Doc
- Volledig Nederlandstalig, responsief en toegankelijk

## Gebruik

Open `index.html` direct in de browser, of host het als statische pagina (geen server nodig).

## Techniek

- Single-page HTML app — geen frameworks, geen build-stap
- Huisstijl Scherp in Veiligheid: `#006a8e` (teal) en `#ff6a13` (oranje)
- Lettertypes: Sora (koppen) + Inter (broodtekst) via Google Fonts
- Dark mode ondersteuning
